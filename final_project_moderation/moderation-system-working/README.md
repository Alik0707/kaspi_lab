Moderation System (Kafka + Redis + Spring Boot)
Разработал систему модерации клиентских обращений на основе событийной архитектуры.
Сервис получает события из Kafka, проверяет бизнес-правила (блокировка клиента, активные заявки, рабочее время), использует Redis для кэширования и идемпотентности, после чего отправляет результат в другой Kafka topic.
Проект полностью контейнеризирован с помощью Docker Compose и включает health-check endpoints.
